# Iconos de Playlistr

El icono representa las cuatro barras de audio que ya formaban parte de la interfaz original de Playlistr. Es una obra original del proyecto y no incorpora el logotipo de Navidrome ni recursos de terceros.

## Archivos

- `playlistr.svg`: icono principal a color.
- `playlistr-animated.svg`: variante animada; desactiva la animación cuando el sistema solicita movimiento reducido.
- `playlistr-dark.svg`: símbolo oscuro sobre fondo transparente.
- `playlistr-light.svg`: símbolo blanco sobre fondo transparente.
- `playlistr.png`: versión estática de 512 × 512 para Unraid y sistemas que no muestran SVG.

Los archivos canónicos se encuentran en `app/static/icons/`. El ZIP de esta carpeta sirve para enviar el conjunto a catálogos como Dashboard Icons.
